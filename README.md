# Cambrius

**Organizational intelligence infrastructure.**

Cambrius is an architecture for turning fragmented organizational information into persistent, connected and evolving knowledge that AI systems can reason over.

Organizations know more than their software does. Useful intelligence is distributed across people, conversations, documents, applications, events and relationships. Cambrius is designed to connect those fragments without requiring a single monolithic system of record.

**Capture → Understand → Organize → Connect → Remember → Analyze → Assist**

## Public research
- **RAG Is Not Organizational Memory** — why retrieval alone is insufficient for persistent organizational knowledge.
- **The Question Nobody Asked** — moving from reactive AI toward systems that recognize meaningful signals without waiting for the perfect prompt.
- **Architecture** — a public overview of the Cambrius intelligence model.

This public repository intentionally excludes private implementation details, customer data, prompts, schemas and domain-specific runtime code.
